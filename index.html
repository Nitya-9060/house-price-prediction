About Project

AI-Based House Price Prediction — an academic prototype.

🎯 Objective

To estimate property prices based on property characteristics and location, using a transparent, ML-inspired simulation that could later be replaced by a real trained model.

🧰 Technologies

  • HTML5
  • CSS3
  • JavaScript (ES6+)
  • Chart.js
  • localStorage
  • Machine Learning Concepts

🔬 How the simulation works

Base price = area × city price-per-sqft, then multiplicative and additive adjustments for type, rooms, furnishing, condition, age, parking, floor and amenities — a feature-weighted linear/boosting-style blend.

🚀 Future Scope

  • Real trained ML model (scikit-learn / XGBoost)
  • Live real-estate datasets
  • Location & map APIs
  • Property image analysis (CNN)
  • Deep learning price models
  • Real-time market data feeds
  • User accounts & saved portfolios
  • Cloud deployment (Docker + cloud hosting)

🛠️ Connecting a Real ML Backend Later

The current JavaScript engine sits in one function (computeValuation() in script.js). To swap in a real model:

  1. Train a regressor (Random Forest, Gradient Boosting or XGBoost) with pandas/NumPy/scikit-learn on real sales data; export with joblib as model.pkl.
  2. Serve it with FastAPI or Flask behind a POST /predict endpoint that accepts the same JSON feature object.
  3. Call the endpoint from the browser with fetch('/predict', {method:'POST', body: JSON.stringify(features)}) and render the returned price exactly as the simulation does now.
